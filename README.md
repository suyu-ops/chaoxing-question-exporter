# 学习通题目导出

适用于学习通页面的浏览器用户脚本，可将当前页面的随堂测验、章节测验、作业和已批阅考试题目整理为题库，并导出为 PDF、DOCX、TXT 或 Markdown。

## 功能

- 提取题干、选项、图片与页面已显示的答案
- 按单选、多选、填空、判断、简答分区整理题目
- 已批阅页面仅显示“我的答案”时，将其填入可在线编辑的附加答案；单题得分只用于内部归类错题，不会写入导出内容
- 批量按课程任务点逐个提取章节测验，支持暂停与继续
- 支持题库保存、编辑、导入、对比和多格式导出

## 安装

1. 在浏览器安装 ScriptCat、Tampermonkey 或兼容的用户脚本管理器。
2. 新建脚本并粘贴 [`学习通题目导出.user.js`](./学习通题目导出.user.js) 的内容。
3. 打开学习通对应页面，使用右侧面板提取、编辑和导出题目。

## 使用说明

- 页面明确展示的正确答案会直接作为附加答案。
- 页面只给出“我的答案”与判题结果时，会把“我的答案”作为可编辑的附加答案；之后可在题库编辑器中按实际情况修改。
- 批量提取会按可见课程任务点依次跳转，并在任务点之间加入等待，避免高频连续跳转。
